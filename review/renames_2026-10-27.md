# Names spelled out — 2026-10-27

After the post-eMudhra review, every variable, type and method name in the code was spelled out in
full, Java style, so that a reader who is not a Go expert can follow it (`proposal`, not `p`;
`ProposalMessage`, not `ProposalMsg`; receivers named after their type, `node *Node`). The rule is in
[`docs/why-small-and-auditable.md`](../docs/why-small-and-auditable.md).

- **What changed:** 2045 objects, on top of `9b7965f`: 1379 local variables, 303 parameters, 232
  receivers, 46 struct fields, 29 constants, 21 functions, 14 types, 11 results, 5 methods, 4
  package variables and 1 type parameter. Commit `803518d` ("names: spell out variable, type and
  method names") made 2044 of them. The next commit updated the comments and the docs and made a
  short second round: receivers that shared their type's name got a name of their own
  (`recorder *recordingTransport`, `pool *mempool`), and six names that read wrong were fixed.
- **What did not change:** behaviour. State digests, signing preimages, persisted JSON and the wire
  format are the same. Two exported fields were renamed (`PreviousStateDigest` on `Block` and
  `Payment`); a tag keeps their JSON key `PrevStateDigest` (2026-10-31: Phase 2, a new genesis,
  dropped that tag, and the key is now `PreviousStateDigest`). Names the wallet's HTML templates use, and
  methods the standard library looks up by name (`String`, `Error`, `UnmarshalJSON`...), were left
  alone.
- **How it was checked:** the rename was applied by a tool, not by hand, and the same tool proves
  the renamed tree is the old program with only names changed. The syntax trees match apart from
  identifiers, every literal and build directive is the same, every identifier resolves to the
  corresponding object (so no new name captures or hides another), every JSON key and option is
  the same, and every type implements the same interfaces with the same methods. On top of that,
  gofmt, go vet, both race test suites (twice) and the chaos and restart tests (five times) passed.
  The tool is in [`_evidence_2026-10-27/renametool/`](_evidence_2026-10-27/renametool/) and the
  maps it applied in [`_evidence_2026-10-27/renames/`](_evidence_2026-10-27/renames/).

To re-run the check yourself (Go 1.27.3):

```sh
mkdir -p /tmp/names-old /tmp/names-new
git archive 9b7965f | tar -x -C /tmp/names-old
git archive 5182d8a | tar -x -C /tmp/names-new
cd review/_evidence_2026-10-27/renametool
GOTOOLCHAIN=auto go run . check /tmp/names-old /tmp/names-new   # prints "check OK" on success
```
